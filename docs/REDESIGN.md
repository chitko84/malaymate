# MalayMate design update

The primary welcome/home artwork is a raised Malaysia map filled with the Malaysian flag, following the supplied reference. It replaces the tiger and the earlier plain flag on a pole. Small navigation flags remain simple for readability.

The purple, mint and cream theme uses clear actions: Learn, Play & explore, Words & phrases, Practice, My progress and Rewards. First-time visitors see short learning steps and two starting actions. Student help explains XP as learning points.

Solo Adventure has nine levels, four gates per level, no countdown and helpful English/Malay feedback. Three correct gates unlock the next level. A first pass awards 30 XP once. Multiplayer uses real two-player rooms with ready checks and live scores. The leaderboard shows actual completed rounds and honest loading, empty and unavailable states.

Three.js renders the scene with a CPU geometry projection fallback for devices without WebGL. Both renderers show the same world. Readable buttons support touch and keyboard use. Nine destinations reuse the stylised world with different content and colours.

The existing lesson, assessment and admin features remain available. The supervisor review page has not been restored. Engagement improvements have not been measured with real learners yet.

## Interactive Malaysia trail

The solo level card grid has been replaced by a tropical Malaysia map. It includes extruded coastlines, beaches, forests, mountains, small buildings, boats and connected trails. Nine clickable stops run through Langkawi, George Town, Ipoh, Kuala Lumpur, Melaka, Johor Bahru, Kuching, Miri and Kota Kinabalu. Location labels are updated in the corresponding games; level IDs, questions and saved results remain compatible. Locked stops can be inspected but cannot be launched. A single selected-stop panel supplies the learning goal and action. The map supports zoom, drag/swipe and keyboard navigation.

## More interactive game scenes

The game challenge is now part of the 3D world. A small mission bubble guides the explorer; clickable portal signs replace the separate form. Free movement, path clicking, jumping, trail coins, opening portals, reward effects and optional sound make each round more active. Both single-player and multiplayer use the same scene controls. Beginner instructions, pause, readable feedback and self-paced play are retained.
